# Klao เกลาคำ

Claude Code skill สำหรับเกลาข้อความภาษาไทย: ตัด "สำนวน AI" และคำที่อธิบายซ้ำกับสิ่งที่จอ
หรือบริบทบอกอยู่แล้ว โดยไม่เปลี่ยนความหมายและไม่กระทบกระบวนการทำงาน

จุดที่ต่างจาก Humanizer ทั่วไป คือ กฎทุกข้อกลั่นจากงานแก้จริงที่ merge แล้ว (ปรับคำใน UI ภาษาไทยมากกว่า 50 จุด และคู่มือรีวิวเนื้อหาขนาดยาวที่ AI ร่าง) ไม่ใช่รายการแปลจากภาษาอังกฤษ และเน้นหนักที่
UI string (empty state, toast, placeholder, aria-label) ที่ยังไม่ค่อยมี skill สายบทความทำเท่าไหร่นัก

## ตัวอย่าง Before → After

ทุกแถวมาจากงานที่ merge แล้วจริง ตัวอย่างเต็ม 17 กลุ่มอยู่ใน [`docs/examples.md`](docs/examples.md)

**สตริงในจอ** ท่าที่มีค่าที่สุดคือตัดหางที่จอบอกอยู่แล้ว ซึ่งหาจากรายการคำไม่ได้

| ก่อน | หลัง | ทำไม |
|---|---|---|
| `ระบบตัดเวลาให้ที่ 8 ชม. — ไม่ได้กดหยุดเอง` | `ตัดเวลาที่ 8 ชม.` | เป็น tooltip บนเซลล์สีเหลือง สีของเซลล์พูดส่วนที่เหลือไปแล้ว |
| `{roleLabel ?? '—'}` | `{roleLabel ?? 'ไม่ระบุ'}` | ขีดเปล่าที่ยืนแทนค่าว่าง อ่านไม่ออกว่าหมายถึงอะไร |
| `{ value: '', label: '— ทีม —' }` | `{ value: '', label: 'เลือกทีม' }` | placeholder เป็นคำสั่ง ไม่ใช่ชื่อช่องในขีดคู่ |
| `บันทึกไม่ได้ — X กำลังแก้ไข` | `X กำลังแก้ไขอยู่ บันทึกไม่ได้` | คนอ่านต้องการผลลัพธ์ก่อนเงื่อนไข |
| `อีเมลของคุณเปลี่ยนแล้ว ต้องเข้าสู่ระบบใหม่` | `อีเมลเปลี่ยนแล้ว ต้องเข้าสู่ระบบใหม่` | ไม่มีอีเมลคนอื่นให้สับสน |

**เนื้อหาไทยยาว** ด่านคนละด่านกับ UI ในเนื้อหาที่ AI ร่าง 828k อักขระ เจอ em-dash 2 ครั้ง
แต่เจอมหัพภาคท้ายประโยคไทย 1,134 ครั้ง

| ก่อน | หลัง | คอร์ปัส |
|---|---|---|
| `แล้วทุกอย่างจะคลี่คลาย.` | `แล้วทุกอย่างจะคลี่คลาย` | 1,134 → 0 |
| `ค่อยๆ ดีขึ้น` | `ค่อย ๆ ดีขึ้น` | 413 → 78 |
| `การเงินอยู่ในเกณฑ์ดีเยี่ยมอย่างยิ่ง` | `การเงินอยู่ในเกณฑ์ดีเยี่ยม` | `อย่างยิ่ง` 97 → 11 |
| `สัตว์เป็นเสื้อคลุมของชาวบ้าน` | `สัตว์เป็นชื่อเล่นของกิ่ง` | อุปมาที่ผู้อ่านต้องถอดรหัส |

**ของที่ Skill นี้เลือกไม่แก้** ครึ่งนี้อยู่ใน `references/false-positives.md` 28 ข้อ
และชนะไฟล์กฎทุกไฟล์ ทุกข้อมีบรรทัด "เป็น tell จริงเมื่อ" ที่บอกว่าข้อยกเว้นสิ้นสุดตรงไหน

| ห้ามแก้ | ทำไม |
|---|---|
| em-dash ใน prose อังกฤษ | ถูกตามหลักภาษา และอาจเป็นลายเซ็นคนเขียน |
| `08:00–20:00` · `8 ชม.` · `พ.ศ.` | ช่วงเวลาและอักษรย่อไทยถูกอยู่แล้ว แม้ grep จะติด |
| `ทุกระบบต้องมีขอบ เพราะตำราคือการบีบชีวิตที่ไม่มีขอบให้ลงตารางที่มีขอบ` | `ขอบ` สามตัวเป็นโซ่ที่มัดข้ออ้างเข้ากับเหตุผล หาคำพ้องความมาสลับแล้วโซ่ขาด |

และในงานบางแบบกฎกลับทิศ เนื้อหาที่ทำนายอนาคตให้ผู้อ่านต้อง **เพิ่ม** hedge
(`จะสำเร็จ` → `มีเกณฑ์สำเร็จ`) เอกสารยื่นลูกค้าต้อง **ขยาย** ประโยคให้เป็นทางการเต็ม ไม่ใช่ย่อ

## ติดตั้ง

```sh
git clone https://github.com/SeedGrit/klao ~/.claude/skills/klao
```

เปิด Claude Code ใหม่ แล้ว `/klao` จะอยู่ในลิสต์ skill ใช้ได้ทุกโปรเจกต์

## ใช้

พิมพ์ `/klao` พร้อมขอบเขต หรือพูดลอย ๆ ก็เปิดใช้ Skill ได้เอง เช่น "เกลาคำหน้านี้", "ตัดสำนวน AI", "อ่านแล้วเหมือน AI เขียน", "ยาวไป"

จบงานจะได้ตาราง Before → After ทุกบรรทัดที่แก้ ให้โต้แย้งได้ทุกรายการ พร้อมรายการตั้งใจละเว้น
พร้อมเหตุผล

Skill นี้ไม่ครอบคลุมการแปลภาษา เขียนเนื้อหาใหม่ ปรับคำเพื่อหลบ AI detector

## กฎที่พลาดง่ายที่สุด

ภาษาไทยปกติไม่ใช้ em-dash กัน แต่ภาษาอังกฤษ (commit body, PR, docs) ใช้ em-dash
ได้ และอาจเป็นสไตล์ของคนเขียนอยู่แล้ว เช่นเดียวกับประโยคอย่าง "not X, but Y" ที่ใช้แยกแยะสาเหตุจริง
skill จึงแยกกฎในภาษาไทย/อังกฤษคนละไฟล์ และเปิดหัวไฟล์อังกฤษด้วยรายการ "ห้ามแก้"

## A. em-dash — tell อันดับ 1

โครงที่ AI ชอบคือ **"เกริ่น — ขยายความ"** ทำให้ทุกประโยคอ่านเป็นจังหวะเดียวกันหมด
วิธีตัดมี 4 ท่า **เลือกตามบริบท ไม่ใช่แทนที่ตายตัว**

### A1 — เว้นวรรคเฉย ๆ (ไทยไม่ต้องมีตัวเชื่อมก็ได้)

| ก่อน | หลัง |
|---|---|
| `บัญชีนี้ยังไม่อยู่ในทีม — แจ้งเจ้าของให้เพิ่มอีเมลของคุณ` | `บัญชีนี้ยังไม่อยู่ในทีม แจ้งเจ้าของให้เพิ่มอีเมลของคุณ` |
| `ยังไม่มีผู้ใช้ — ตั้งคุณเป็น owner คนแรก` | `ยังไม่มีผู้ใช้ ตั้งคุณเป็น owner คนแรก` |
| `ยังไม่มีปฏิทิน — เพิ่มด้านล่าง` | `ยังไม่มีปฏิทิน เพิ่มด้านล่าง` |
| `เพิ่มไม่สำเร็จ — ตรวจ URL อีกครั้ง` | `เพิ่มไม่สำเร็จ ตรวจ URL อีกครั้ง` |
| `เบราว์เซอร์นี้ไม่รองรับการแจ้งเตือน — ลองใช้ Chrome, Edge หรือ Safari รุ่นใหม่` | `เบราว์เซอร์นี้ไม่รองรับการแจ้งเตือน ลองใช้ Chrome, Edge หรือ Safari รุ่นใหม่` |
| `รายงานประจำวัน — สรุปงานเมื่อวานส่งเข้ากลุ่มทุกเช้า` | `รายงานประจำวัน สรุปงานเมื่อวานส่งเข้ากลุ่มทุกเช้า` |

### A2 — ใช้คำเชื่อมไทย (คือ / ที่ / ซึ่ง / จึง / แล้ว / เพราะ / เมื่อ)

| ก่อน | หลัง |
|---|---|
| `ฟ้าซ้อนฟ้า — พลังหยางบริสุทธิ์ที่เคลื่อนไม่หยุด.` | `ฟ้าซ้อนฟ้าคือพลังหยางบริสุทธิ์ที่เคลื่อนไม่หยุด.` |
| `มังกรยังหลบอยู่ใต้น้ำ ยังไม่ถึงเวลาแสดงตัว — สะสมกำลังไว้ก่อน` | `มังกรยังหลบอยู่ใต้น้ำ ยังไม่ถึงเวลาแสดงตัว จึงควรสะสมกำลังไว้ก่อน` |

### A3 — วงเล็บ เมื่อหางเป็นหมายเหตุจริง ๆ (คนละระดับกับประโยคหลัก)

| ก่อน | หลัง |
|---|---|
| `ยังไม่ได้ตั้ง token — ผู้ดูแลรัน wrangler secret put MY_TOKEN` | `ยังไม่ได้ตั้ง token (ผู้ดูแลรัน wrangler secret put MY_TOKEN)` |

### A4 — ตัดหางทิ้ง เมื่อหางพูดซ้ำสิ่งที่จอบอกอยู่แล้ว ⭐ ท่าที่มีค่าที่สุด

| ก่อน | หลัง | ทำไม |
|---|---|---|

| `เพิ่มปฏิทินแล้ว — กำลัง sync รอบแรก` | `เพิ่มปฏิทินแล้ว กำลัง sync` | "รอบแรก" ไม่ได้ให้ข้อมูลกับคนที่เพิ่งกดเพิ่ม |
| `อัปเดตเวอร์ชันเมื่อไหร่จะแจ้งทีม — ถ้า v ด้านบนใหม่กว่าที่คุณมี ให้ดาวน์โหลดทับ` | `ถ้า v ด้านบนใหม่กว่าที่คุณมี ให้ดาวน์โหลดทับอีกครั้ง` | ครึ่งแรกเป็นสัญญา ไม่ใช่คำสั่งที่ทำได้ตอนนี้ |
| `ยังไม่มีอุปกรณ์ที่เปิดแจ้งเตือน — เปิดด้านบนก่อน ไม่งั้นตั้งไว้ก็ไม่มีอะไรมา` | `ยังไม่มีอุปกรณ์ที่เปิดแจ้งเตือน เปิดด้านบนก่อน` | หางเป็นการหยอด |
| `ลิงก์นี้เปิดได้ทุกคนที่มี URL — อย่าส่งต่อ, อย่าโพสต์สาธารณะ, และอย่าแชร์ออกนอกกลุ่ม` | `ลิงก์นี้เปิดได้ทุกคนที่มี URL อย่าส่งต่อ อย่าโพสต์สาธารณะ` | สามข้อคือ tricolon ข้อสามซ้ำข้อแรก |

## B. ขีดเปล่าแทนค่าว่าง

`—` ที่ยืนแทนชื่อที่หายไปหรือลิสต์ว่าง อ่านไม่ออกว่าหมายถึงอะไร

| ก่อน | หลัง |
|---|---|
| `{roleLabel ?? '—'}` | `{roleLabel ?? 'ไม่ระบุ'}` |
| `{comment.authorName ?? '—'}` | `{comment.authorName ?? 'ไม่ระบุ'}` |
| `<span>—</span>` (ลิสต์สมาชิกว่าง) | `<span>ไม่พบสมาชิก</span>` |
| `<div>—</div>` (ไม่มีสถิติ) | `<div>ไม่มีข้อมูล</div>` |
| `แก้ไขล่าสุดโดย {note.updatedByName ?? '—'}` | `{note.updatedByName && (<div>แก้ไขล่าสุดโดย {note.updatedByName}</div>)}` |
| `{p.total > 0 ? hm(p.total) : '—'}` | `{p.total > 0 ? hm(p.total) : ''}` (ในตารางที่ช่องว่างอ่านออกเอง) |

**สี่ทางเลือก เรียงตามลำดับที่ควรลอง:** ไม่แสดงบรรทัดนั้นเลย → เว้นว่าง (ในตาราง) →
คำที่บอกว่าทำไมถึงว่าง (`ไม่พบสมาชิก`) → คำกลาง ๆ (`ไม่ระบุ`)

## D. เอาข้อสรุปขึ้นก่อน

AI ชอบเปิดด้วยเงื่อนไข/ข้อจำกัดแล้วค่อยเฉลย คนอ่านต้องการผลลัพธ์ก่อน

| ก่อน | หลัง |
|---|---|
| `บันทึกไม่ได้ — ${name} กำลังแก้ไข` | `${name} กำลังแก้ไขอยู่ บันทึกไม่ได้` |
| `งานนี้ไม่มีชื่อคุณเป็นผู้รับผิดชอบ — อยู่ในลิสต์เพราะวันนี้คุณกดจับเวลาไว้` | `อยู่ในลิสต์เพราะวันนี้คุณกดจับเวลาไว้ ไม่ได้เป็นผู้รับผิดชอบ` |
| `แสดงงานล่าสุดบางส่วน (มีมากเกินไป) — ใช้ตัวกรองช่วย` | `งานเยอะเกิน แสดงเฉพาะล่าสุด ใช้ตัวกรองช่วย` |
| `ครบ 8 ชม. ของวันนี้แล้ว — เริ่มจับเวลาใหม่ไม่ได้` | `วันนี้ครบ 8 ชม. แล้ว เริ่มจับเวลาใหม่ไม่ได้` |

## E. คำที่บริบทถืออยู่แล้ว

| ก่อน | หลัง | ตัดอะไร |
|---|---|---|
| `อีเมลของคุณเปลี่ยนแล้ว ต้องเข้าสู่ระบบใหม่` | `อีเมลเปลี่ยนแล้ว ต้องเข้าสู่ระบบใหม่` | `ของคุณ` — ไม่มีอีเมลคนอื่นให้สับสน |

| `รายละเอียดยาวเกินไป ตัดออกอีก N ตัวอักษรก่อนบันทึก` | `รายละเอียดยาวเกินไป ตัดออกอีก N ตัวอักษร` | `ก่อนบันทึก` — ปุ่มบันทึกอยู่ตรงนั้น |

## H. Tells สำหรับ prose ยาว (เนื้อหา / บทความ)

### H1 `ไม่ใช่ X แต่ (คือ) Y`
AI ตีกรอบด้วยการปฏิเสธก่อน คนไทยพูดตรงกว่า
`การตั้งหลักให้มั่นก่อนเดินต่อไม่ใช่ความอ่อนแอ แต่คือความรอบคอบ.`
→ `การตั้งหลักให้มั่นก่อนเดินต่อคือความรอบคอบ.`

### H2 `ยิ่ง X ยิ่ง Y`
`จังหวะนี้ยิ่งไปด้วยกันยิ่งไปได้ไกล.` → `จังหวะนี้ไปด้วยกันจะไปได้ไกลกว่า.`

### H3 Closer สำเร็จรูป
`นั่นคือ…ที่แท้จริง` · `และนั่นคือ…` · `อย่างงดงาม` · `อย่างแท้จริง`
วิธีแก้: เปลี่ยนเป็นรูปธรรม หรือ**จบก่อนถึง closer** ถ้าประโยคก่อนหน้าอิ่มแล้ว

### H4 Tricolon ทุกครั้ง
"ตั้งรับ สนับสนุน และอดทน" มีบ้างได้ แต่อย่าให้ทุกบล็อกเป็นสูตรเดียว
สลับเป็นสอง/หนึ่ง/สี่ให้จังหวะต่างกัน

### H5 Adverb stacking `อย่าง + คุณศัพท์`
`อย่างงดงาม / อย่างแท้จริง / อย่างลึกซึ้ง / อย่างสง่างาม` ซ้ำ ๆ = ฟุ้ง
`นำโชคดีมาให้อย่างงดงาม.` → `นำโชคดีมาให้.`

### H6 โครงประโยคซ้ำข้ามบล็อก
ถ้าเปิดประโยคด้วยท่าเดียวกันเกือบทุกอัน ("A ซ้อน B —") = ท่าเดียว
สลับการเปิด (ด้วยภาพ / ด้วยสถานการณ์ / ด้วยคำถามในใจ)

### H7 คำเชื่อมฟุ่มเฟือย + nominalization
`ซึ่ง / อันเป็น / โดยที่ / อย่างไรก็ตาม` เกินจำเป็น, `สิ่งที่… / การที่…`

### H8 Hedging เกินเหตุ
`อาจจะ / ค่อนข้าง / ในบางที` ทำให้คำแนะนำอ่อน — house voice = ตรงไปตรงมา
(แต่ไม่ฟันธงหายนะ)
